# ATP-20261019-01

Unga rankingklättrare, ursprungligt uttag 2026-10-19.

- `query.sql`: ursprunglig databasfråga. Ny körning kan ge ändrade värden.
- `results.json`: samtliga 17 sparade kandidater med ranking och observationsdatum.
- `metadata.json`: definitioner och sortering.
- `render.py`: renderar bilden från sparat resultat med Pillow och macOS Arial.
- `unga-rankingklattrare.png`: delningsbar bild med analys-ID och urvalsregler.

Rendera från projektroten med `.venv/bin/python analysis/ATP-20261019-01/render.py`. Inga externa faktakällor användes. Exakt klockslag för originaluttaget finns inte sparat.
